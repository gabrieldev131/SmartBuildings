1. ARCHITECTURAL RULES & S.O.L.I.D. COMPLIANCE
----------------------------------------------
Every Python module in the project enforces two strict structural rules:
- Rule 1: At most 1 class per file (`.py`).
- Rule 2: At most 20 lines per function or method.

How the S.O.L.I.D. Principles are implemented across the folders:
- [S] Single Responsibility Principle (SRP):
  Every package and class has a single well-defined responsibility:
  * `domain/` holds pure data structures and the `GlobalIdentity` entity.
  * `interfaces/` holds pure abstract contracts (`ABC`), one per file.
  * `behaviors/` holds self-contained behavioral plugins (`StoppedStateTracker`, `RestrictedZoneAnalyzer`).
  * `exporters/` holds self-contained data sinks (`CsvTrajectoryExporter`, `KafkaEventExporter`).
  * `identity/` holds cross-camera identity resolution (`GlobalIdentityManager`) and topology (`CameraClusterManager`).
  * `extraction/` holds asynchronous video stream capture (`RTSP`, `MP4`, `Kafka`).
  * `vision/` holds GPU detection (`BatchInferenceEngine`), feature extraction (`featureExtractor`), and per-camera tracking (`CameraWorker`, `StabilizedTrack`).
  * `ui/` holds OpenCV rendering (`MultiCameraDisplay`).

- [O] Open/Closed Principle (OCP) & Elimination of `if/else` Chains:
  * `exporters/ExporterRegistry.py` and `behaviors/BehaviorRegistry.py` implement the Self-Registering Plugin Registry Pattern with `pkgutil.iter_modules` automatic module discovery.
  * Adding 100 new export sinks or 100 new behavior rules requires ZERO `if/else` statements and ZERO edits to existing code: simply drop a new single-class file into `exporters/` or `behaviors/` decorated with `@ExporterRegistry.register("name")` or `@BehaviorRegistry.register("name")`, and list its name in `Config.ACTIVE_EXPORTERS` or `Config.ACTIVE_BEHAVIORS`.

- [L] Liskov Substitution Principle (LSP):
  * `ReadRTSPCommand` and `ReadKafkaCommand` are interchangeable implementations of `IFrameCommand`.
  * `CsvTrajectoryExporter` and `KafkaEventExporter` are interchangeable implementations of `IDataExporter`.
  * `StoppedStateTracker` and `RestrictedZoneAnalyzer` are interchangeable implementations of `IBehaviorAnalyzer`.
  * `StabilizedTrack` is a behavioral subtype of `deep_sort_realtime.deep_sort.track.Track`.

- [I] Interface Segregation Principle (ISP):
  * Interfaces are split into small, focused contracts in `interfaces/`:
    `IFrameCommand.py`, `ICommandFactory.py`, `IBehaviorAnalyzer.py`, `IDataExporter.py`, `IIdentityRepository.py`, and `IStateTracker.py`.

- [D] Dependency Inversion Principle (DIP):
  * High-level modules (`CameraWorker`, `GlobalIdentityManager`, `BehaviorPipeline`, `ExportPipeline`, `FrameReaderInvoker`) depend on the abstract interfaces in `interfaces/`.


2. FOLDER-BY-FOLDER & FILE-BY-FILE EXPLANATION
----------------------------------------------

A. ROOT CONFIGURATION & ENTRYPOINT
----------------------------------
- `main.py`:
  Configures logging, applies native thread and CUDA/TF32 limits (`identity.runtime_setup.apply`), instantiates `Config` and `FrameReaderManagement`, and starts the system with `multiprocessing` spawn mode.
- `Config.py`:
  Centralizes all system parameters:
  * Hardware & execution: `USE_GPU`, `EXECUTION_MODE` (`"batched"` or `"multiprocess"`), `USE_CUDA_GRAPHS`, `MAX_DETECTIONS_PER_CAMERA = 18`.
  * YOLO26n detection & chair/furniture filtering: `YOLO_CONF_THRESHOLD = 0.40`, `YOLO_INIT_CONF = 0.48`, `MIN_ASPECT_RATIO = 0.18`, `MAX_ASPECT_RATIO = 0.95`.
  * `deep-sort-realtime` parameters: `DEEPSORT_MAX_AGE = 90`, `DEEPSORT_N_INIT = 2`, `DEEPSORT_MAX_COSINE_DISTANCE = 0.40`, `DEEPSORT_MAX_IOU_DISTANCE = 0.72`.
  * Active Behavior Plugins tuple: `ACTIVE_BEHAVIORS = ("stopped",)`.
  * Active Data Exporters tuple: `ACTIVE_EXPORTERS = ("csv",)` (add `"kafka"` to stream events to Kafka).

B. `domain/` — DOMAIN ENTITIES & VALUE OBJECTS
----------------------------------------------
- `domain/BoundingBox.py`: Dataclass encapsulating `[x1, y1, x2, y2]` and geometric properties (`width`, `height`, `area`, `aspect_ratio`, `center`).
- `domain/FramePacket.py`: Dataclass encapsulating `(cam_id, frame, timestamp, seq_id)`.
- `domain/TrackContext.py`: Dataclass passed to every `IBehaviorAnalyzer` on each frame (`global_id`, `local_id`, `cam_id`, `bbox`, `current_time`, `confidence`).
- `domain/BehaviorResult.py`: Dataclass returned by `IBehaviorAnalyzer.analyze(...)` specifying `name`, `is_active`, `label_suffix`, `color_override`, `event_type`, `duration_seconds`, and `details`.
- `domain/AnnotationSpec.py`: Dataclass holding the resolved HUD `bbox`, `global_id`, `label`, and `color`.
- `domain/GlobalIdentity.py`: Domain entity for a unique person across cameras. Uses `scipy.spatial.distance.cdist` for hybrid cosine matching across a multi-pose gallery, per-camera EMA memory, and global EMA centroid, with outlier rejection and diversity-preserving updates.

C. `interfaces/` — APPLICATION PORTS (ABCs)
-------------------------------------------
- `interfaces/IFrameCommand.py`: `execute()` and `cleanup()` contract for video stream readers.
- `interfaces/ICommandFactory.py`: `__call__()` contract for serializable command factories.
- `interfaces/IBehaviorAnalyzer.py`: `from_config(config)` and `analyze(context)` contract for behavior plugins.
- `interfaces/IDataExporter.py`: `from_config(config)`, `on_event(event)`, `export(records)`, and `cleanup()` contract for data exporters.
- `interfaces/IIdentityRepository.py`: Contract for `GlobalIdentityManager`.
- `interfaces/IStateTracker.py`: Contract for `update_and_evaluate(global_id, box, current_time)`.

D. `behaviors/` — PLUG-AND-PLAY BEHAVIORAL ANALYTICS (ZERO `if/else`)
---------------------------------------------------------------------
- `behaviors/BehaviorRegistry.py`:
  Implements `@BehaviorRegistry.register("name")` and `discover_plugins()` via `pkgutil.iter_modules`. Instantiates all plugins listed in `Config.ACTIVE_BEHAVIORS` via dictionary lookup without `if/else`.
- `behaviors/BehaviorPipeline.py`:
  Composite runner that evaluates all active `IBehaviorAnalyzer` plugins on each person's `TrackContext`, builds the HUD `AnnotationSpec`, and forwards active events to `GlobalIdentityManager.record_behavior_event`.
- `behaviors/StoppedStateTracker.py`:
  Registered as `@BehaviorRegistry.register("stopped")`. Uses a sliding time deque and spatial hysteresis (`STOPPED_PIXEL_THRESHOLD`, `MOVEMENT_BREAKOUT_THRESHOLD`) to detect stationary/loitering people.
- `behaviors/RestrictedZoneAnalyzer.py`:
  Registered as `@BehaviorRegistry.register("restricted_zone")`. Alerts whenever a person enters a normalized bounding region.

E. `exporters/` — PLUG-AND-PLAY DATA EXPORTERS (ZERO `if/else`)
---------------------------------------------------------------
- `exporters/ExporterRegistry.py`:
  Implements `@ExporterRegistry.register("name")` and `discover_plugins()` via `pkgutil.iter_modules`. Instantiates all exporters listed in `Config.ACTIVE_EXPORTERS` via dictionary lookup without `if/else`.
- `exporters/ExportPipeline.py`:
  Formats chronological events, per-camera passages (`CAMERA_PASSAGE`), and cluster summaries (`AMBIENTE_SUMMARY`), dispatches real-time events via `notify_event(event)`, and dispatches final consolidated records via `export_all(identities, events)`.
- `exporters/CsvTrajectoryExporter.py`:
  Registered as `@ExporterRegistry.register("csv")`. Writes consolidated records to `tracking_data_final.csv`.
- `exporters/KafkaEventExporter.py`:
  Registered as `@ExporterRegistry.register("kafka")`. Publishes JSON tracking events in real time (`on_event`) and consolidated summaries (`export`) to `Config.KAFKA_EVENTS_TOPIC` using `confluent_kafka.Producer`.

F. `identity/` — CROSS-CAMERA RE-ID & TOPOLOGY CLUSTERING
---------------------------------------------------------
- `identity/CameraClusterManager.py`:
  Thread-safe wrapper around `scipy.cluster.hierarchy.DisjointSet` (Union-Find) that merges cameras into shared spatial `Ambientes` when a person transitions between them within `AUTO_CLUSTER_TIME_THRESHOLD`.
- `identity/GlobalIdentityManager.py`:
  Manages intra-camera and cross-camera Re-ID matching (`get_or_create_global_id`, `update_existing_identity`), spatial-temporal proximity bonuses, online provisional identity consolidation, and event dispatching to `ExportPipeline`.
- `identity/IdentityManagerServer.py`:
  `BaseManager` RPC server used when `EXECUTION_MODE = "multiprocess"`.
- `identity/runtime_setup.py`:
  Configures OpenMP/MKL/OpenCV threads and PyTorch cuDNN/TF32 flags.

G. `vision/` — YOLO26n, TORCHVISION RE-ID & `deep-sort-realtime`
----------------------------------------------------------------
- `vision/GraphSlot.py`:
  Encapsulates static GPU tensors and double-buffered page-locked (`pin_memory=True`) host buffers for a specific camera batch size `B`.
- `vision/BatchInferenceEngine.py`:
  Fuses Ultralytics `YOLO26n` (`one2one` head), suppresses non-person and furniture classes (`56..62`: chairs, couches, tables, TVs) on GPU, crops detected people via `torchvision.ops.roi_align`, extracts 576D embeddings via `MobileNetV3-Small` inside a captured `torch.cuda.CUDAGraph`, and filters boxes with `torchvision.ops.nms` and `torchvision.ops.box_iou`.
- `vision/featureExtractor.py`:
  Computes 576D L2-normalized embeddings fusing deep semantic stripes, mid-level texture stripes, and Gray-World white-balanced color/chromaticity stripes.
- `vision/StabilizedTrack.py`:
  Subclass of `deep_sort_realtime.deep_sort.track.Track` (injected via `override_track_class=StabilizedTrack`) adding occlusion velocity damping, tentative-track 1-frame blink survival (`mark_missed`), EMA bounding-box smoothing, and outlier-filtered EMA appearance updates.
- `vision/cameraWorker.py`:
  Per-camera worker that runs `deep_sort_realtime.deepsort_tracker.DeepSort`, suppresses duplicate overlapping tracks via `torchvision.ops.box_iou`, resolves Global IDs with `GlobalIdentityManager`, evaluates behavior plugins via `BehaviorPipeline`, and annotates frames.

H. `extraction/` & `ui/` — VIDEO STREAM CAPTURE & PRESENTATION
--------------------------------------------------------------
- `extraction/FrameReaderManagement.py`:
  Orchestrates background `FrameReaderInvoker` threads and the double-buffered GPU/CPU loop (overlapping GPU Batch `t` with CPU tracking for Batch `t-1`).
- `extraction/CameraProcess.py`:
  Worker process entrypoint for `"multiprocess"` mode.
- `extraction/frameReaderCommand/`:
  Command Pattern implementations (`ReadRTSPCommand.py`, `ReadKafkaCommand.py`), factories (`RTSPCommandFactory.py`, `KafkaCommandFactory.py`), and background thread invoker (`FrameReaderInvoker.py`).
- `ui/display.py`:
  OpenCV HUD drawing functions (`draw_annotation_spec`, `draw_camera_hud`) and `MultiCameraDisplay` window manager.
